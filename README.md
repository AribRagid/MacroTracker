# MacroTracker

Personal mobile calorie and protein tracker. Plain HTML, CSS, and JavaScript; no build step or login.

## GitHub Pages
Publish the main branch from the repository root in Settings > Pages.

## Data
Entries, goals, and theme are saved in the browser using localStorage. Tracking days begin at 3 a.m. local time. Settings provides JSON backup download and import. Moving from another website requires exporting there and importing here because browser storage is specific to each origin.
